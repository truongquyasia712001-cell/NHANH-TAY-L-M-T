# Nhanh Tay Lẹ Mắt — Demo chơi thật

## Chạy local
```bash
npm install
npm start
```
Mở http://localhost:3000

## Demo
- Mở 1 tab MC, 1 tab Sân khấu, và 2+ tab/thiết bị Player.
- Mã phòng mặc định: ABC123.
- MC chỉnh thời gian, bắt đầu câu hỏi, chuyển câu hoặc vào Grand Finale.
- Tất cả đội tiếp tục thi đấu đến Grand Finale.

## Lưu ý
Đây là bản demo realtime để kiểm thử luồng chơi. Chưa phải production: chưa có database bền vững, tài khoản, RBAC, anti-cheat nâng cao, backup và hạ tầng phân tán.
